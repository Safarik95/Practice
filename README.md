# Музыкальная программа

Учебная практика, вариант 2 «Музыкальная программа». Оконное приложение на C++20 и Qt 6 Widgets, которое помогает организатору составить порядок музыкальных номеров мероприятия. Каждый номер имеет уникальный числовой код, название, исполнителя и продолжительность от 1 до 86 400 секунд.

## Возможности

- добавление номера в начало или в конец программы;
- отмена первого или последнего номера;
- поиск по фрагменту названия без учёта регистра, пустая строка показывает все номера, поиск не меняет программу;
- просмотр в обычном и обратном порядке без перестановки номеров;
- перенос первых k номеров в конец с сохранением порядка, k от 0 до числа номеров;
- суммарная продолжительность и изменение продолжительности номера по коду;
- сохранение и загрузка состояния в JSON.

Ограничения: код от 1 до 1 000 000 и уникален, название и исполнитель от 1 до 100 символов после удаления пробелов по краям, не более 1000 номеров. При ошибке данные не меняются, а в окне выводится понятное сообщение.

## Окружение

- Windows 10
- Qt 6.12.1, комплект MinGW 15.1.0 64-bit
- CMake 3.30.5, Ninja 1.12.1
- Qt Creator 21.0.0
- Стандарт языка: C++20
- Необходимые компоненты Qt: Core, Widgets, Test

## Структура

- `src/track.h` — структура номера;
- `src/result.h` — результат операции с сообщением об ошибке;
- `src/program.h`, `src/program.cpp` — предметная логика, номера хранятся в `std::deque`;
- `src/storage.h`, `src/storage.cpp` — сохранение и загрузка JSON;
- `src/mainwindow.h`, `src/mainwindow.cpp` — главное окно;
- `src/main.cpp` — точка входа;
- `tests/` — автоматические тесты на Qt Test;
- `data/` — примеры файлов данных.

Предметная логика и работа с файлами собраны в статическую библиотеку `music_core`, которую используют и приложение, и тесты, поэтому логика проверяется без создания окна.

## Сборка и запуск

1. Открыть `CMakeLists.txt` в Qt Creator (File → Open File or Project).
2. Выбрать комплект Desktop Qt 6.12.1 MinGW 64-bit и нажать Configure Project.
3. Собрать проект и запустить цель `MusicProgram`.

## Тесты

Тесты написаны на Qt Test и зарегистрированы в CTest: `test_program` проверяет предметную логику, `test_storage` проверяет сохранение, загрузку и отказ при ошибочных файлах.

Запуск в Qt Creator: Tools → Tests → Run All Tests.

Запуск из консоли в каталоге сборки (`ctest` входит в комплект CMake, установленный вместе с Qt):

```
ctest --output-on-failure
```

Каталог Qt с библиотеками добавляется в `PATH` для тестов автоматически через `CMakeLists.txt`.

## Формат файла

Состояние сохраняется в JSON в кодировке UTF-8:

```json
{
    "formatVersion": 1,
    "variant": 2,
    "state": {
        "tracks": [
            {"code": 101, "title": "Увертюра", "artist": "Городской оркестр", "duration": 240}
        ]
    }
}
```

Массив `tracks` хранит номера в порядке программы. Файл больше 1 МиБ, повреждённый JSON, другая версия формата или другой вариант, а также неверные данные номеров (повторный код, пустые поля, недопустимая длительность, нецелые числа) отклоняются целиком, текущая программа при этом не меняется. Неизвестные дополнительные поля игнорируются. Запись выполняется через `QSaveFile`, поэтому при сбое старый файл не повреждается.

## Демонстрационные файлы

В каталоге `data`:

- `example.json` — корректная программа из пяти номеров;
- `broken.json` — повреждённый JSON;
- `wrong_version.json` — неподдерживаемая версия формата;
- `duplicate_code.json` — повторный код номера.

## Известные ограничения

- Приложение проверялось только на Windows 10.
- AddressSanitizer не поддерживается компилятором MinGW, поэтому не использовался.
- Воспроизведение аудио и работа с музыкальными файлами не предусмотрены условием.
